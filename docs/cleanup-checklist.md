- [ ] Elastic IP 해제 — 할당했다면 주소/확인 시각:
- [ ] NAT Gateway 삭제 및 상태 `Deleted` 확인 — 생성했다면 ID/시각:
- [ ] ELB/ALB 삭제 — 생성했다면 이름/시각:
- [ ] RDS 삭제 — 생성했다면 식별자/시각:
- [ ] Internet Gateway VPC에서 분리 후 삭제:
- [ ] Subnet 및 사용자 생성 Route Table 삭제:
- [ ] Security Group 삭제(기본 그룹 제외):
- [ ] VPC 삭제:
- [ ] 서울 리전에서 실습 리소스 잔존 여부 재확인:

현재 상태: 미실행. AWS 인증 및 배포가 완료된 뒤 이 체크리스트를 갱신해야 합니다.
